# Правила роботи в репозиторії

- **`README.md` — завжди англійською.** Кожна зміна README пишеться англійською, навіть якщо
  розмова чи решта документації українською.
- Коментарі в коді та `docs/` — українською.
- Інтерфейс застосунку — українською.
- Нове архітектурне рішення або зміна старого → запис у `docs/decisions.md` у тому самому коміті.
